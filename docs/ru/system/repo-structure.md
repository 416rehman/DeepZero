## Структура репозитория

```text
src/deepzero/
├── __init__.py          # Определения SemVer
├── __main__.py          # Точка входа модуля
├── cli.py               # Интерфейс приложения Click
├── api/                 # Конечные точки Starlette REST
├── engine/              # Основная логика выполнения и оркестрации
│   ├── backends/        # Подключаемые бэкенды LLM, выбираемые по схеме модели
│   └── report.py        # Сборка HTML-отчета из состояния запуска
└── stages/              # Стандартная библиотека процессоров

processors/              # Предоставленные и эталонные процессоры
├── ghidra_decompile/    # Безголовый декомпилятор Ghidra (Map)
├── git_ingest/          # Обнаружение и клонирование git-репозиториев (Ingest)
├── loldrivers_filter/   # Фильтр исключения хешей loldrivers.io (Map)
├── pe_ingest/           # Разбор заголовков PE и метаданных драйверов (Ingest)
└── semgrep_scanner/     # Пакетное сканирование Semgrep (BulkMap)

pipelines/               # Объявления и логика конвейеров
├── loldrivers/          # Исследование драйверов ядра BYOVD
└── source_audit/        # Аудит исходного кода в git-репозиториях

docs/                    # Документация GitHub Pages на Jekyll
tests/                   # Тестовый пакет Pytest
```

Каталог каждого конвейера содержит его `pipeline.yaml`, шаблоны промптов Jinja, которые рендерят его этапы LLM, и правила semgrep, которые загружает его этап сканирования. Чтобы добавить конвейер, ничего за пределами этого каталога менять не нужно, и в этом весь смысл: `pipelines/` и `processors/` читаются по пути, а не регистрируются в коде.
